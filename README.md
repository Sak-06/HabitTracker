HabitTracker App is a mobile application designed to help users build and maintain positive habits. By providing an intuitive interface for tracking daily activities, it empowers users to stay consistent and achieve their personal goals.

**Features**
Add, edit, and delete habits with ease

Track daily progress through an interactive calendar view

Visualize habit streaks and completion rates

AI chatbot that gives advices on healthcare and habits

Responsive design for seamless use across devices
